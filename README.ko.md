# Grokbot City

[English](README.md) · 한국어

봇에게 업무를 맡기고, 어느 단계까지 진행했는지 확인하고, 결과를 지식으로 남기는 로컬 대시보드입니다.

사용자는 화면에서 지침과 업무지시서를 작성합니다. 메인봇은 이를 읽고 CLI로 진행 상황과 결과를 기록합니다. 앱이 직접 Grok에 연결하거나 언어 모델을 실행하지는 않으므로, 봇이 설치된 PC의 파일과 CLI에 접근할 수 있어야 합니다.

## 업무지시서를 작성하고, 준비되면 전달하세요

![카테고리별 색상 보드에 정리된 업무지시서](docs/images/task-briefs.png)

*설명을 위해 가상 데이터를 넣어 촬영한 실제 앱 화면입니다. 새로 설치하면 샘플 업무와 위키 문서는 들어 있지 않습니다.*

아직 시작하지 않은 업무는 카테고리별 보드에서 정리합니다. 카테고리명을 누르면 이름과 보드 색상을 바꿀 수 있습니다. 개인 업무에는 담당 봇을, 팀 업무에는 Boss와 최대 5명의 팀원을 지정합니다.

지시서를 저장하면 이 공간에 남습니다. 준비가 끝났을 때 **진행** 토글을 켜세요. 메인봇이 접수하면 **모니터링**으로 이동합니다.

## 지금 어떤 단계를 진행하는지 확인하세요

![왼쪽 업무지시서와 오른쪽 노드별 진행 상황을 함께 보여 주는 상세 화면](docs/images/task-flow.png)

모니터링에서는 업무를 **대기중·진행중·완료**로 나누어 봅니다. 업무를 누르면 왼쪽에 지시서, 오른쪽에 봇이 작성한 작업 흐름이 열립니다. 각 노드에 담당 봇과 상태, 진행률이 표시되어 어느 단계에서 작업하고 있는지 알 수 있습니다.

봇은 업무 시작, 단계 전환, 완료 시점에 상태를 기록합니다. 변경 내용은 새로고침 없이 화면에 반영됩니다. 루틴 업무는 회차별 실행 이력을 남기며, 다음 회차도 봇이 확인해서 시작합니다.

## 끝난 업무에서 배운 내용을 남기세요

![위키 문서 간 연결 지도와 선택한 문서를 함께 보여 주는 업무 도서관](docs/images/wiki-map.png)

완료한 업무는 **업무 도서관**에 보관합니다. 봇은 사용한 방법, 시행착오, 결과를 Markdown 결과서로 남기고, 메인봇은 이 원자료를 서로 연결된 위키 문서로 정리합니다. **업무 wiki MAP**에서는 문서 사이의 연결을 따라가며 내용을 읽을 수 있습니다.

보관한 업무를 복원하면 **업무지시서**로 돌아갑니다. 원래 업무를 복원하거나 삭제해도 위키의 지식은 유지됩니다. 위키 내용을 고치거나 지우려면 메인봇에게 별도로 요청하세요.

## 봇마다 역할과 지침을 관리하세요

왼쪽 목록에서 봇을 선택하면 지침과 주요 업무를 볼 수 있습니다. 지침을 수정한 뒤에는 봇의 확인을 기다리는 표시가 생기고, 봇이 적용을 확인하면 적용 날짜가 기록됩니다.

- 메인봇 1개와 추가 봇 6개의 빈 프로필로 시작합니다. 더 필요하면 메인봇이 `bot.create`로 추가할 수 있습니다.
- Codex, Claude Code, 기타 CLI의 활용 정도를 봇마다 설정하거나 메인봇의 설정을 전체에 적용할 수 있습니다. 봇이 참고할 지침이며, 설정만으로 도구가 설치되거나 실행되지는 않습니다.
- 한국어와 영어 UI를 지원합니다. 어두운 화면에 Paperlogy 폰트를 사용하며, 움직임 감소 설정도 반영합니다.

## 내 PC에서 시작하기

**Node.js 24 이상**을 설치한 뒤 아래 명령을 실행하세요.

```sh
git clone https://github.com/sleeplesshan/grokbot-city.git
cd grokbot-city
npm ci
npm run build
npm start
```

브라우저에서 **http://127.0.0.1:4318**을 여세요. ZIP으로 내려받았다면 압축을 푼 폴더에서 터미널을 열고 `npm ci`부터 실행하면 됩니다.

처음 실행하면 `data/`에 데이터베이스, PC 설정, 로컬 봇 인증 키를 만듭니다. 이 파일들은 내 PC에 보관되며 Git에 포함되지 않습니다. 앱 안에 시연 모드는 없습니다.

### 메인봇에게 첫 운영 지침 전달하기

1. 왼쪽 메뉴의 **운영 가이드**를 엽니다.
2. 설치한 PC와 프로젝트 폴더의 절대경로를 입력합니다.
3. 시작 프롬프트를 복사해 메인봇에게 전달합니다. 메인봇은 해당 PC에서 파일을 읽고 CLI를 실행할 수 있어야 합니다.

프롬프트에는 읽어야 할 문서, 실제 봇 이름·사진을 등록하는 방법, 현재 진행 중인 업무를 모니터링에 옮기는 절차가 들어 있습니다. 저장소의 [운영 가이드](docs/OPERATING_GUIDE.md)에서도 복사할 수 있습니다.

`data/bot.key`는 공개하지 마세요. 실제 프로필 사진은 Git에서 제외되는 `public/assets/local/`에 넣고, 추가한 뒤 다시 빌드하면 됩니다.
